HTMLの演出を、動画に重ねる方法

「HTML/CSS」でコピーしたコードは、背景が透明の動画に書き出して、元の動画に重ねられます。Claudeに頼むなら、依頼文カテゴリーの「HTMLの演出を動画に重ねる」で一括して任せられる。自分で試す場合は、次のスクリプトを使います。

# render_overlay.py
# 使い方: python render_overlay.py motion.html 3 overlay.mov
#   motion.html : 素材集の「HTML/CSS」ボタンでコピーしたコードを保存したファイル
#   3           : 書き出す長さ(秒)
#   overlay.mov : 出力ファイル(背景が透明の動画)
# 事前に: pip install playwright && playwright install chromium (ffmpegも必要)
import os, shutil, subprocess, sys
from playwright.sync_api import sync_playwright

html, secs, out = sys.argv[1], float(sys.argv[2]), sys.argv[3]
W, H, FPS = 1080, 1920, 30
os.makedirs("frames", exist_ok=True)

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page(viewport={"width": W, "height": H})
    page.goto("file://" + os.path.abspath(html))
    page.evaluate("document.fonts.ready")
    page.wait_for_timeout(600)
    for i in range(int(secs * FPS)):
        t = i * 1000 / FPS
        # アニメーションを止めて、i番目のフレームの時刻に合わせる
        page.evaluate("t => document.getAnimations().forEach(a => { a.pause(); a.currentTime = t; })", t)
        page.screenshot(path="frames/f%05d.png" % i, omit_background=True)
    browser.close()

subprocess.run(["ffmpeg", "-y", "-framerate", str(FPS), "-i", "frames/f%05d.png",
                "-c:v", "prores_ks", "-profile:v", "4444", "-pix_fmt", "yuva444p10le", out], check=True)
shutil.rmtree("frames")
print("done:", out)

書き出した overlay.mov を、2秒の位置から動画に重ねるコマンドです。

ffmpeg -i input.mp4 -itsoffset 2 -i overlay.mov -filter_complex "[0:v][1:v]overlay=0:0:eof_action=pass,format=yuv420p" -c:a copy out.mp4

素材のコードは自由に使えます。フォントはGoogle Fontsの無料フォント。BGMや映像素材は含みません。

効果音のサンプルは、ブラウザの中で簡易的に作った音。本番では、カードの「依頼文」でClaudeに作ってもらうか、ffmpegのコマンドで作ります。

ASS字幕の位置と大きさは、縦動画(1080×1920)が前提。横動画に使うときは、PlayResXとPlayResYを書き換えます。
